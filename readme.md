## Games

ICH has a bunch of game hubs, each packed with its own set of games, so there's always something new to try. Pick a hub and start playing, no downloads or accounts needed.

## What is this?

ICH is a chat hub with a big collection of games built in. Jump in, talk to people, and play whatever you're in the mood for. This repo just holds the backup links in case the main site goes down.
